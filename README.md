# All About Me

I DO NOT want to remember my public SSH keys. So, I'll put them here.

```
ssh/
├── identities/   public keys that prove a DEVICE is connecting
└── hosts/        public keys that prove a SERVER is who it claims to be
```

See [ssh/README.md](ssh/README.md) for which is which and how to use them.

**Public keys only.** Nothing in this repository is secret, and nothing secret
should ever be added to it.
